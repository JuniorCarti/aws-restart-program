- Practice with type() and print() functions

## Python Data Types Covered

### 1. int (Integer)
- Whole numbers without decimals
- Example: `myValue = 1`

### 2. float (Floating Point)
- Numbers with decimal points
- Example: `myValue = 3.14`

### 3. complex (Complex Numbers)
- Numbers with real and imaginary parts
- Example: `myValue = 5j`

### 4. bool (Boolean)
- Logical values: True and False
- Implemented as subset of int (1=True, 0=False)
- Examples: `myValue = True`, `myValue = False`

## Key Functions Used
- `print()` - Output values to console
- `type()` - Get data type of variable
- `str()` - Convert to string for concatenation
